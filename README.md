Wedding Fun Hub 💍🎉

An interactive wedding-themed web application built to entertain guests and create engagement during wedding events through quizzes, leaderboards, and fun interactive features.

🚀 Features

- 🎯 Interactive Couple Quiz
- 🏆 Real-time Leaderboard System
- 🔥 Firebase Integration
- 📱 Responsive User Interface
- 🎨 Modern and Clean Design
- ⚡ Smooth User Experience
- 🧠 Dynamic Quiz Logic
- 📊 Score Tracking System



🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase



📂 Project Structure

–index.html
-style.css
-script.js
-firebase-config.js
└── assets/



🔧 Firebase Features

This project uses Firebase for:

- Data storage
- Leaderboard management
- User interaction handling
- Real-time updates



💡 Project Goal

The goal of this project is to create a fun and engaging digital experience for wedding guests through interactive activities and live competition features.
